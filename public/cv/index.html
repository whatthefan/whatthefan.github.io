The proof

PLEA5E

My own product · live and selling · design, code, back end, copy

NFC and QR plaques that send a business's customers straight to its Google review page. I own the whole thing: the physical product, the brand, the site, the ordering system and the after-sales. It runs on Cloudflare Workers and it takes real orders.

  • Hand-written front end. No framework, no template, no page builder — 1,657 lines of my own CSS and roughly 3,100 lines of my own JavaScript, so the page loads fast and nothing on it is someone else's default.
  • A 3D preview in the browser. The customer sees their own plaque rendered in WebGL before paying, and turns it around with a finger.
  • A back end that does the work. Six API endpoints handle the order, generate the design with Anthropic's Claude, and send the confirmation mail through Resend. Keys live in the environment, never in the repository.
  • A brand with a character. The mascot has 42 drawn poses — walk cycles, waves, a jump — generated from a single Python script so a new pose costs minutes, not an afternoon in Illustrator.
  • Built to be handed over. A 55 KB manual in plain Spanish lets a non-programmer change prices, links and legal text without calling me. Fifty-three commits, each one written so the next person understands it.

If you hire me, the first month

A sporting event is a deadline you cannot move, so the plan runs backwards from it. This is what I would do, in order — you can hold me to it.

  1. Week 1Fix the grid before anything elseThe magazine's type scale, column grid and ad slot sizes, defined once so the print page and the app screen are the same system. Get this wrong and every later page costs double.
  2. Week 2One issue, end to endA single real issue built as a working mobile prototype — cover, feature, and a live ad slot — so you are approving something you can hold, not a mood board.
  3. Week 3The advertiser's sideThe rate card, the ad formats and the page we send advertisers to. Selling space is easier when the buyer can see exactly what they get and what it costs.
  4. Week 4Ship it and measure itThe app live, analytics on the ad slots, and a repeatable process so issue two takes a fraction of issue one.
