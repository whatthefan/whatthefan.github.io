# packs2/: SFX de los 3 vídeos-guía que pasó Juan (voz quitada con Demucs)
Cada sonido tiene **su** efecto visual (en `capas/fx.js`) y se usa solo para eso:
- `whoosh-b`, `swoosh-a`, `swish-c`, `whoosh-dramatico` → **whip**: barrido lateral con desenfoque de movimiento entre escenas
- `obturador-flash` → **flash**: flash blanco de cámara + punch (a/desde la cara)
- `glitch` → **glitch**: RGB separado + franjas (corte raro)
- `braam` → **impacto** grande (palabra gigante, revelación seria)
- `riser-impacto` → **riser** (tensión 1,5 s: zoom lento, temblor, oscurecer) + **impacto** en el golpe
- `riser-metal` → riser antes de `woah-drop` (producto)
- `synth-hit` → **zoomdig** o impacto suave: empezar una escena, la marca
- `zoom-digital` → zoom digital a saltos · `pop-imagen` → aparece una imagen/objeto
- `teclas` → texto a máquina (con cursor) · `contador` → números o chips que avanzan · `carga` → barra de carga
- `whoosh-mov` → alguien o algo que se mueve en escena
Todos se sacaron enteros; si la fuente cortaba, se añadió una cola de reverb suave. **Nunca cortar un sonido** salvo teclas o contador (con fundido).
